BUILT FOR OPEN EXTENSION

A clear path from discovery to install.

The catalogue stays in GitHub, packages stay inspectable, and DIOXAMINE's own installer remains in control.

01

Discover

Browse a public catalogue with version, source, compatibility, and permission details.

02

Inspect

Every package lives in the repository with its metadata and a verifiable SHA-256 digest.

03

Install

Compatible ZIPs are handed to DIOXAMINE's current plugin installer for validation.
